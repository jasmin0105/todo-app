# Мини-проект: Список задач (To-Do)

«Список задач» — веб-приложение из трёх частей: фронтенд в браузере, бэкенд на Python (Flask) и база данных PostgreSQL. Части общаются по HTTP, данные передаются в формате JSON.
Приложение выполняет четыре базовые операции над задачами (CRUD: создать, прочитать, изменить, удалить). Дополнительно есть приоритеты (низкий, средний, высокий), сроки выполнения, поиск, сортировка, фильтры, плитки статистики, полоска прогресса, пять цветовых тем и тёмная тема.

Полноценное веб-приложение из трёх частей:

| Часть       | Технология              | Файл                                                        |
| ----------- | ----------------------- | ----------------------------------------------------------- |
| Фронтенд    | HTML + CSS + JavaScript | `static/index.html`, `static/style.css`, `static/script.js` |
| Бэкенд      | Python + Flask          | `app.py`                                                    |
| База данных | PostgreSQL              | таблица `tasks` в базе `todo_db` (`schema.sql`)             |

## Запуск

1. **Создать базу данных.** В DataGrip подключись к своему PostgreSQL, открой консоль запросов и выполни:
   ```sql
   CREATE DATABASE todo_db;
   ```
2. **Проверить настройки подключения** в начале `app.py` (блок `DB_CONFIG`):
   хост `localhost`, порт `5432`, пользователь `postgres`, пароль — впиши свой.
3. **Установить библиотеки и запустить:**
   ```bash
   pip3 install -r requirements.txt
   python3 app.py
   ```
4. Открыть в браузере: http://127.0.0.1:5000

Таблица `tasks` создаётся автоматически при запуске.

## Подключение DataGrip к базе

`+` → `Data Source` → `PostgreSQL` → Host `localhost`, Port `5432`, User `postgres`,
Password (свой), Database `todo_db` → `Test Connection` → `OK`.
Потом: `todo_db` → `public` → `tables` → `tasks`.

## API

| Метод  | Адрес             | Что делает                           |
| ------ | ----------------- | ------------------------------------ |
| GET    | `/api/tasks`      | получить все задачи                  |
| POST   | `/api/tasks`      | добавить задачу                      |
| PUT    | `/api/tasks/<id>` | отметить выполненной / невыполненной |
| DELETE | `/api/tasks/<id>` | удалить задачу                       |

## Как это работает (для пересказа)

1. Пользователь открывает страницу, браузер загружает HTML, CSS и JS.
2. JS через `fetch()` отправляет запрос на сервер (`GET /api/tasks`).
3. Flask принимает запрос, через библиотеку `psycopg2` делает SQL-запрос к PostgreSQL и возвращает задачи в формате JSON.
4. JS получает JSON и рисует список задач на странице.
5. При добавлении / изменении / удалении JS отправляет POST / PUT / DELETE, сервер выполняет INSERT / UPDATE / DELETE в базе, и список обновляется.

Схема: **Браузер (фронтенд) ⇄ Flask (бэкенд) ⇄ PostgreSQL (база данных)**
